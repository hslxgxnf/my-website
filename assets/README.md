# Variable Naming

## `-` → `_`

## `space` → `_`

## `.` → `$`

### Examples

- `custom-properties.txt` → `custom_properties$txt`
- `Stack Overflow` → `Stack_Overflow`
- `Next.js` → `Next$js`
- `GitHub` → `GitHub`

# Image Naming

## `space ` → `-`

### Examples

- `Stack Overflow` → `Stack-Overflow`
- `Next.js` → `Next.js`
- `GitHub` → `GitHub`
- `_dummy`
  - Special Case
