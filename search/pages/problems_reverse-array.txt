Reverse Array # [Last Updated: July 13, 2026]
Problem #
Given an array, reverse it in place.
Examples #
[1, 4, 3, 2, 6, 5] [Output] [5, 6, 2, 3, 4, 1]
[4, 5, 2] [Output] [2, 5, 4]
[1] [Output] [1]
Constraints #
$1 \le n \le 10^5 \ (\text{array length})$
$0 \le v \le 10^5 \ (\text{element value})$
Expected Complexities #
Time Complexity: $\mathcal{O}(n)$
Auxiliary Space: $\mathcal{O}(1)$
Solution #
```code
Python
from typing import TypeVar

T = TypeVar("T")


def reverse_array_single_pointer(arr: list[T]) -> list[T]:
    for i in range(len(arr) // 2):
        arr[i], arr[-1 - i] = arr[-1 - i], arr[i]

    return arr


def reverse_array_two_pointers(arr: list[T]) -> list[T]:
    left_index: int = 0
    right_index: int = len(arr) - 1

    while left_index < right_index:
        arr[left_index], arr[right_index] = arr[right_index], arr[left_index]
        left_index += 1
        right_index -= 1

    return arr


print(reverse_array_single_pointer([1, 4, 3, 2, 6, 5]))
print(reverse_array_single_pointer([4, 5, 2]))
print(reverse_array_single_pointer([1]))
```
