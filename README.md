# [hslee.dev](https://hslee.dev)

Welcome to the repository for [hslee.dev](https://hslee.dev), a personal digital garden for exploring, reviewing, and deepening engineering insights.

## Tech Stack

- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: SCSS
- Math Rendering: KaTeX
- State Management: Zustand
- Crawling: Playwright
- Analytics: Vercel Analytics & Vercel Speed Insights
- Deployment: Vercel

## Getting Started

```bash
# Clone the repository
git clone https://github.com/hslxgxnf/my-website.git

# Navigate to the directory
cd my-website

# Install dependencies
npm install

# Start the local development server
npm run dev
```
